# Cyber Incident Analytics

## Project Overview

Cyber Incident Analytics is a data analytics project focused on analyzing cyber incidents to identify patterns, trends, attack types, affected countries, attribution, and incident intensity.

The project was developed using Excel, SQL, and Power BI to perform data cleaning, analysis, transformation, data modeling, and interactive visualization.

## Objective

The main objectives of this project are:

- Analyze cyber incident data and identify important trends.
- Understand different types of cyber incidents and attacks.
- Analyze incidents based on countries and regions.
- Study incident intensity and other key indicators.
- Perform SQL-based data analysis and extraction.
- Build an interactive Power BI dashboard for data-driven insights.

## Tools & Technologies

- Microsoft Excel – Data cleaning, transformation, pivot tables, pivot charts, and exploratory analysis.
- MySQL – Data extraction, filtering, aggregation, joins, and analytical SQL queries.
- Power BI – Data transformation, data modeling, DAX calculations, KPIs, slicers, and interactive dashboard development.

## Project Workflow

### 1. Excel Analysis

- Performed data cleaning and formatting.
- Handled missing and inconsistent values.
- Analyzed the dataset using Pivot Tables.
- Created Pivot Charts to identify trends and patterns.
- Performed country-wise and incident-wise analysis.

### 2. SQL Analysis

- Imported the datasets into MySQL.
- Created and structured tables.
- Performed data extraction and transformation using SQL.
- Used filtering, aggregation, grouping, joins, and analytical queries.
- Generated insights from cyber incident data.

### 3. Power BI Dashboard

- Connected and transformed the data using Power Query.
- Created relationships and data models.
- Developed DAX measures for key metrics.
- Created an interactive Cyber Incident Analytics dashboard.
- Added KPIs, charts, slicers, and filters for interactive analysis.

## Key Analysis Performed

- Total number of cyber incidents
- Incident trends over time
- Incident types and attack categories
- Country-wise incident analysis
- Incident intensity analysis
- Attribution analysis
- Cyber conflict analysis
- Analysis of initiators and receivers
- Comparison of incidents across different dimensions
